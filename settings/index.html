Camera wall setup

Give the wall read access to the camera videos already registered with Homey.

  1. In Homey, open Settings → API Keys and choose New key.
  2. Name it Eufy camera wall and allow Device read access.
  3. Copy the key and paste it below.

The key is stored on Homey. A saved key is never shown here.
